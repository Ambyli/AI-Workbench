🚀 Zeo Service Chatbot — System Upgrades & Architecture

Production System Summary: All recent architectural enhancements, model integrations, concurrency queueing, and test suites are live in this deployment.

1. vLLM Engine & Qwen 3.8 27B Model Integration

  • OpenAI-compatible client querying /v1/chat/completions with JSON schema structured output decoding at temperature: 0.0.
  • Defaulting to model qwen3.8:27b / Qwen/Qwen2.5-27B-Instruct with automatic fallback on server outages.

2. Active User Concurrency Limiting & Real-Time FIFO Queue

  • Hard capacity cap on concurrent active users (MAX_ACTIVE_USERS).
  • Overflow users enter a real-time FIFO waiting queue with live position tracking and automatic slot promotion upon session completion or 5-min idle timeout.
  • Simulate load right from the top queue widget bar.

3. Production Dockerization & Lifecycle Control

  • Multi-stage lightweight Python 3.11 container running as non-root appuser.
  • Cross-platform start/stop scripts (scripts/docker-start.sh / .ps1).

4. CRM Case Management & Chatter Note Templates

  • Disposition pipeline generates real-time CRM cases with automated routing.
  • Interactive Mock CRM tab displaying formatted Chatter notes, customer verbatim statements, and visual damage photo galleries.

5. Comprehensive Security Hardening (8/8 Test Suites Passed)

  • Deterministic 911 safety gates, prompt injection XML sandboxing, header magic-byte verification, Pillow EXIF stripping, and rate limiting.
